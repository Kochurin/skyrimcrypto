# Crypto Notepad

Текстовый редактор с клиентским шифрованием (Zero-Knowledge Cloud Notepad).
Заметка шифруется в браузере; сервер хранит только зашифрованный пакет и не знает ни пароля, ни текста.

Проект реализует модель из лабораторных работ 1–7 («Современные подходы и методы автоматизации деятельности организации»).
Техническое решение — Sol_5 из ЛР3: Web Crypto API, монолит на Node.js, PostgreSQL, S3-хранилище.

## Структура (компоненты из ЛР7)

| Папка | Компонент | Статус |
|---|---|---|
| `packages/crypto` | K1.2 Криптомодуль (интерфейс ICrypto) | готов, этап 1 |
| `apps/api` | K2 Backend-сервер API | этап 2 |
| `apps/web` | K1.1 Веб-редактор | этап 3 |
| `docker-compose.yml` | K3 PostgreSQL, K4 MinIO (S3) | файл готов, нужен Docker Desktop |

## Формат зашифрованного пакета (v1)

```json
{
  "v": 1,
  "kdf":    { "alg": "PBKDF2-SHA256", "iterations": 600000, "salt": "<16 байт, base64url>" },
  "cipher": { "alg": "AES-256-GCM", "iv": "<12 байт, base64url>" },
  "ciphertext": "<шифротекст + тег 16 байт, base64url>"
}
```

- Ключ: PBKDF2-HMAC-SHA-256, 600 000 итераций по умолчанию (допускается 100 000 – 10 000 000), соль 16 байт из CSPRNG, пароль в NFC.
- Шифр: AES-256-GCM, новый IV 12 байт на каждое шифрование, тег 128 бит.
- Заголовок (версия, алгоритмы, итерации, соль, IV) передаётся в GCM как AAD: его подмена обнаруживается так же, как подмена шифротекста.
- Ключ неэкспортируемый (`extractable: false`).

## План

0. Каркас — готово
1. Криптомодуль — готово
2. Бэкенд: `POST /notes`, `GET /notes/:id`, PostgreSQL + MinIO
3. Фронтенд: сценарии US-01 и US-02 (MVP)
4. Аккаунты, список заметок, удаление и TTL
5. Защита: Rate Limiting, журнал без содержимого, HTTPS, CSP
6. Администрирование: квоты, `/health`, бэкапы, аудит
7. Качество: Playwright в трёх браузерах, нагрузочные тесты, PWA
